How it works

From a question to a finished lesson

No slides to build and no script to write. ShikhaAI handles each step and shows you its work along the way.

  1. 1

    Enter a topic and a grade

    Ask anything, from why the sky is blue to L’Hôpital’s rule. The grade level you pick sets the vocabulary, depth and pacing of the script.

  2. 2

    Choose video or podcast

    Get a narrated, illustrated video with the script alongside it, or a conversation between two hosts. Pick a quality tier so you know the cost before anything is generated.

  3. 3

    Watch, listen, come back

    Every lesson is saved with its script to a searchable library on your computer. Replay it as often as it takes, then quiz yourself on what it covered.

Two formats

One topic, two ways to take it in

Some learners need to see an idea. Others need to hear it talked through. ShikhaAI does both from the same prompt.

A narrated, illustrated video

ShikhaAI writes a grade-appropriate script, illustrates every scene and narrates it with slow pan-and-zoom motion instead of static slides. The full script stays on screen, so learners can read along as they listen.

  • Choose a narrator voice, and preview it before you generate
  • Set how many illustrated scenes each video has
  • Regenerate a single scene from the storyboard without re-rendering the rest
  • Play, pause and resume with built-in controls

A conversation between two hosts

Shimmer and Echo, one energetic and one thoughtful, talk your topic through with humor and real-world examples. It sounds like a podcast, not a lecture read aloud.

  • Playback speed from 0.75× to 2×
  • Optional ambient music bed, off by default, with adjustable volume
  • Music is synthesized on your computer, so there’s no licensed audio involved
  • Saved to your library with the full script

Accessibility

Designed for learners who need more than one way in

Students with ADHD, dyslexia, autism or processing differences often understand far more than a fast-moving lesson gives them room to show. ShikhaAI gives them other ways to take an idea in, and as much time as they need.

  • See it, hear it, read it

    Video lessons are narrated scene by scene, with the complete script on screen to read along at the same time.

  • Set the level, not the label

    Choose any grade level. A student can revisit a concept at an earlier grade, or work ahead, without anyone calling it remedial or advanced.

  • Go at your own pace

    Pause, resume and replay any lesson as often as needed. Podcasts play anywhere from 0.75× to 2× speed.

  • Fix the scene that didn’t land

    If one illustration is confusing, regenerate just that scene from the storyboard instead of remaking the whole video.

  • Calm by default

    Background music stays off unless you turn it on, and the app uses quiet in-app messages instead of system pop-ups.

  • A voice that’s easy to follow

    Preview narrator voices before generating, and choose the one that works best for each learner.

  • Captions built for focus

    ADHD-friendly captions follow the narration word by word, with a set number of words on screen and optional bold word starts for focus reading.

  • Quizzes without the pressure

    Quizzes are built from the lesson’s own script. Extra time, a calm timer with no color warnings, and a pause that hides the question make a break a real break.

  • One-tap accessibility presets

    ADHD focus, autism and sensory-friendly, and dyslexia-friendly presets turn on captions, reduced motion, larger text, extra line spacing and more.

A learning tool, not a clinical one

ShikhaAI doesn’t diagnose or treat any condition. It works best alongside the teachers, families and specialists who know each learner.

Cost

Free to use. You decide what each lesson costs.

ShikhaAI runs on your own OpenAI API key, so you pay OpenAI directly for what you generate. There’s no subscription and nothing added on top.

  • Budget

    The lowest cost per lesson. Good for trying out topics and testing ideas.

  • Balanced

    Default

    The everyday setting. A typical short video costs well under $0.50.

  • Higher quality

    Sharper writing and more detailed illustrations, for lessons you plan to reuse or share with a class.

API prices are set by OpenAI and change over time. See current OpenAI pricing

Install

Set up in about five minutes

Everything you need is listed here, in order. Nothing is hidden in a README you have to go hunting through.

You’ll need

  • Python 3.9 or newer
  • VLC media player, for playback
  • An OpenAI API key with billing enabled

Released October 25, 2026 · ZIP, 1.3 MB · Needs Python 3.9 or newer

  • New: ADHD-friendly captions on videos and podcasts
  • New: quizzes built from each lesson, with extra time and a calm timer
  • New: accessibility presets for ADHD, autism and dyslexia
Download v1.0.1
  1. 1

    Download ShikhaAI and install its packages

    Download the ZIP, unzip it, and open a terminal inside the ShikhaAI-1.0.1 folder. Then run:

    Terminal 
    $ pip install -r requirements.txt
  2. 2

    Add your OpenAI API key

    Copy .env.example to a new file named .env in the same folder, then set your key:

    .env 
    OPENAI_API_KEY=sk-your-key-here
  3. 3

    Start ShikhaAI

    Terminal 
    $ python run.py

    That’s the whole setup. Everything else happens inside the app.
